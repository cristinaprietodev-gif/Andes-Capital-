# Andes-Capital-
# 📈 Dashboard de Desempeño Comercial & Calidad de Datos - Andes Capital

## 🎯 Objetivo 
Realizar una auditoría integral de calidad de datos (*Data Quality*) y diseñar un tablero de control de Business Intelligence para monitorear el desempeño de ventas, el comportamiento de compra de los clientes y la rentabilidad por categoría.

---

## 💡 Insights de Negocio
* **Auditoría de Datos:** Identificación y tratamiento de datos faltantes bajo patrones MAR/MCAR y tratamiento de valores atípicos (*outliers*) en montos de venta.
* **Segmentación de Clientes:** Clasificación de clientes de alto valor (*whales*) vs. compradores ocasionales para focalizar esfuerzos comerciales.
* **Rendimiento Financiero:** Visualización de tendencias de venta mensuales e identificación de las categorías con mayor margen de ganancia.

---

## 🚀 Recomendaciones Estratégicas
1. **Gobierno de Datos:** Establecer reglas de validación en la captura de datos de clientes para evitar valores nulos en el sistema origen.
2. **Estrategia Comercial:** Crear programas de fidelización para los clientes pertenecientes al segmento de mayor ticket promedio.

---

* **Data Quality & BI:** Limpieza de datos, definición de KPIs y diseño visual para toma de decisiones ejecutivas.
